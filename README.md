# 💜 MilfaCheatHUB

**MilfaCheatHUB** — проект с разными Lua-скриптами и интерфейсами для игр в Roblox.

Мы создаём единый узнаваемый GUI-стиль для всех скриптов проекта: тёмный, компактный и атмосферный интерфейс в духе Minecraft PvP-клиентов, адаптированный под Roblox.

## 🎮 Что мы делаем

- Разрабатываем разные скрипты для игр Roblox.
- Разделяем интерфейс и игровую логику по отдельным Lua-модулям.
- Создаём удобные вкладки, кнопки, переключатели, слайдеры и настройки.
- Поддерживаем единый визуальный стиль MilfaCheatHUB во всех проектах.
- Загружаем модули и изображения через GitHub RAW-ссылки.

> Возможности каждого скрипта зависят от конкретной игры Roblox.

## 🖥️ Стиль интерфейса

GUI MilfaCheatHUB сочетает стиль современных Roblox-интерфейсов с эстетикой тёмного Minecraft Cheat Client / PvP GUI:

- почти чёрный основной фон;
- тёмно-фиолетовые полупрозрачные панели;
- неоновые cyberpunk-акценты;
- компактная боковая навигация с иконками;
- аккуратные секции настроек в несколько колонок;
- плавные скругления и мягкие тени;
- тонкие разделители и подсветка активной вкладки;
- переключатели, слайдеры, списки и поля ввода в едином стиле;
- серо-белый текст с яркими цветными акцентами;
- пиксельный или близкий к игровому шрифт;
- полупрозрачное чёрно-фиолетовое наложение поверх игры.

Интерфейс должен оставаться читаемым и не перекрывать большую часть игрового экрана.

## 🗂️ Категории GUI

Каждая категория получает собственный неоновый цвет:

- 🩷 **Бой** — боевые функции и настройки.
- 🔵 **Движение** — перемещение и управление персонажем.
- 🟪 **ESP** — визуальные элементы и отображение объектов.
- 🟢 **Игрок** — параметры локального персонажа.
- 🔷 **Мир** — взаимодействие с окружением игры.
- 🟡 **Прочее** — дополнительные и сервисные возможности.

## 🧩 Рекомендуемая структура

```text
MilfaCheatHUB/
├── main.lua
├── modules/
│   ├── ui.lua
│   └── features.lua
├── games/
│   └── game-name.lua
└── assets/
    └── logo.png
```

`main.lua` выступает точкой входа, `modules/ui.lua` отвечает за общий интерфейс, а игровые функции хранятся отдельно, чтобы проект было удобно расширять.

## ✨ Правила дизайна MilfaCheatHUB

1. Использовать тёмную основу и один яркий цвет для активной категории.
2. Не перегружать экран: важные настройки должны находиться в компактных секциях.
3. Сохранять одинаковые размеры элементов, отступы и скругления.
4. Подсвечивать активные кнопки мягким неоновым свечением.
5. Использовать короткие и понятные названия функций.
6. Делать интерфейс удобным как на большом, так и на небольшом экране.
7. Во всех игровых скриптах сохранять фирменную палитру MilfaCheatHUB.
